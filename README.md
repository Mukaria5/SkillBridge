# 🎓 SkillBridge

**Connect. Collaborate. Build Together.**

SkillBridge is a modern, responsive student collaboration platform developed using **HTML5**, **CSS3**, and **JavaScript**. The website demonstrates core Internet Programming concepts while providing an attractive glassmorphism user interface and interactive user experience.

---

## 📌 Project Overview

SkillBridge enables students to:

* 🤝 Connect with other students
* 💻 Showcase technical and creative skills
* 🚀 Collaborate on academic and personal projects
* 🎨 Explore student services
* 📷 View multimedia content
* 📩 Contact the platform through an interactive form

This project was developed as an **Internet Programming CAT 3** assignment.

---

# ✨ Features

* Modern Glassmorphism User Interface
